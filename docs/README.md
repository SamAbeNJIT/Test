# Postline Signs: UX Project

A sign-company ordering flow modeled on **Sticker Mule**, built for a UX class.

## Prototype
Open `site/index.html` in a browser. It's one self-contained file. Full flow:
**Home → Product (size/qty/live price) → Upload → Cart → Checkout → Confirmation → Proof (request changes / approve)**.
Use "Fill with example details" at checkout. No real payments are taken.
